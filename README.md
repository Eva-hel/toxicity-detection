# toxicity-detection

## Quick start

```
conda env -n toxicity-detection-model-training python=3.11 -y
conda activate toxicity-detection-model-training
python -m pip install -r requirements.txt
```

### Model inference

**Запуск на встроенном наборе примеров:**
```
python .\src\model_training\inference.py
```

**Анализ текста из консоли:**
```
python .\src\model_training\inference.py --text "Ну и бред ты несешь, клоун" --show_confidence
```

**Интерактивный режим:**
```
python .\src\model_training\inference.py --interactive --show_confidence
```


## Pipeline explanation

### Data

#### Dataset

В проекте используется датасет [RuParaDetox](https://huggingface.co/datasets/s-nlp/ru_paradetox) — русскоязычный параллельный корпус, предназначенный для детоксикации текстов. Он содержит пары токсичных комментариев и их нейтрализованных аналогов, в которых сохраняется исходный смысл сообщения при снижении уровня токсичности.

Датасет содержит два основных поля:

- `ru_toxic_comment` — исходный токсичный комментарий.
- `ru_neutral_comment` — нейтрализованная версия исходного комментария.


#### Toxicity taxonomy

Для выявления и классификации токсичных языковых паттернов была разработана собственная таксономия, включающая шесть категорий:

| Категория            | Описание                                                                                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `profanity`          | Ненормативная лексика, бранные слова и ругательства общего характера, не направленные непосредственно против конкретного человека.                                   |
| `insult`             | Прямые оскорбления личности, направленные на унижение её характера, внешности, интеллекта или других качеств.                                                        |
| `derogation_mockery` | Уничижительные ярлыки, саркастические выражения, намеренное искажение слов и насмешки.                                                                               |
| `threat_violence`    | Угрозы физической расправой, причинением вреда или пожелания смерти.                                                                                                 |
| `harassment_doxxing` | Призывы к травле, деанонимизации или раскрытию персональной информации.                                                                                              |
| `hate_speech`        | Язык вражды и дискриминационные высказывания, направленные против отдельных лиц или групп по признаку расы, национальности, гендера и другим признакам идентичности. |

Основная задача разметки заключается в выявлении конкретных фрагментов токсичного текста (*toxic spans*), а не в присвоении единой метки токсичности всему комментарию. Каждый найденный фрагмент относится к одной из шести категорий.

#### Pseudo-labeling

Поскольку исходный датасет содержит токсичные комментарии и их нейтрализованные аналоги, но не включает разметку токсичных фрагментов на уровне отдельных слов и выражений, для автоматического создания таких аннотаций был реализован пайплайн на основе большой языковой модели (LLM).

Для разметки используется локально запущенная модель **Qwen2.5 14B Instruct**. 

Процесс псевдоразметки включает следующие этапы:

1. **Загрузка датасета** 
2. **Формирование промпта** 
3. **Инференс языковой модели** 
4. **Валидация и выравнивание разметки**
5. **Сохранение результатов** 

Пайплайн также сохраняет информацию о прогрессе разметки, что позволяет пропускать уже обработанные примеры при повторном запуске скрипта.

В результате формируется аннотированный датасет, который используется в качестве основы для последующей подготовки данных и обучения модели обнаружения токсичности.

#### Postprocessing

В получившейся разметки датасета распределение токсичных языковых паттернов выглядит следующим образом:

- profanity: 8220
- derogation_mockery: 381
- insult: 5803
- threat_violence: 215
- hate_speech: 164
- harassment_doxxing: 9

В связи с недостаточным числом выявленных паттернов "harassment doxxing" решено исключить этот паттерн из датасета, посредством удаления объектов, где этот паттерн был выявлен. 

Помимо этого в получившейся разметке наблюдаются случаи, когда у одного и того же текста выявлялись различные токсичные языковые паттерны. Само наличие нескольких одинаковых текстов в тренировочной выборке, а так же различные значения таргетов для этих объектов нежелательно при обучении модели. В качестве решения этой проблемы использовался подход объединения разных результатов разметки для одного текста в один объект. 

**Итоговое число уникальных текстов:** 6939

**Соотношение train/val:** 0.85/0.15
